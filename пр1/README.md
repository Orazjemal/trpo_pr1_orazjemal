# Практическая работа № 1 — Веб-старт

## Результат

Адаптивная одностраничная информационная страница на чистых HTML и CSS. Она знакомит с основами frontend-разработки и использует учебные направления из исходного набора `dataset`.

## Запуск

Откройте `index.html` в любом современном браузере. Сборка, сервер и установка зависимостей не нужны. Относительные пути к стилям, данным и изображениям позволяют перемещать каталог целиком.

## Структура проекта

- `index.html` — семантическая структура: шапка, навигация, основной контент и подвал.
- `css/styles.css` — типографика, Flexbox, карточки, таблица, состояния фокуса и мобильные медиазапросы.
- `data/content.csv` — исходные 6 тем курса с категориями, описаниями и числовыми значениями.
- `data/navigation.json` — исходные пункты меню и целевые идентификаторы разделов.
- `images/logo.svg`, `images/cover.svg` — изображения из dataset.

## Как применены данные

Шесть строк `content.csv` представлены в виде карточек и повторены как шесть записей в таблице. Сохранены названия, категории, описания и значения `value`. В исходном CSV значения лежат в диапазоне 6–10; в интерфейсе шкала «из 10» добавлена как пояснение. Ссылки меню из `navigation.json` ведут на `about`, `tracks`, `schedule` и `signup`.

## Объяснение решений

1. `lang="ru"`, UTF-8 и `viewport` дают браузеру сведения о языке, кодировке и отображении на телефоне.
2. `header`, `nav`, `main`, `section`, `article` и `footer` описывают назначение частей страницы. Это упрощает навигацию скринридером и делает документ понятнее.
3. Однотипные карточки используют одинаковую структуру и класс `.card`; Flexbox переносит карточки на следующую строку, а на узком экране включается одна колонка.
4. Таблица содержит `caption`, `thead`, `tbody`, заголовки `th` и минимум пять строк. На узких экранах её можно прокручивать внутри области, не расширяя всю страницу.
5. В форме каждому элементу ввода соответствует `label`. Типы `email` и `number`, атрибуты `required`, `min`, `max`, `minlength` и `maxlength` включают встроенную проверку браузера.
6. `box-sizing: border-box` делает расчёт ширины предсказуемым. `:focus-visible` показывает клавиатурный фокус, а ссылка пропуска к основному содержимому помогает клавиатурным пользователям.
7. Все изображения заданы относительными путями. Иллюстрация имеет осмысленный `alt`; логотип декоративный и потому имеет пустой `alt`.
8. Форма демонстрационная: `action="#signup"` не отправляет сведения на сервер. Для настоящей регистрации потребовался бы серверный обработчик и политика хранения персональных данных.

## Ответы на контрольные вопросы

1. Приложение использует строки `data/content.csv`, пункты меню `data/navigation.json` и SVG-изображения из `images/`. В этой статической версии значения данных перенесены в HTML вручную, что прямо разрешено заданием для первого этапа.
2. Отдельного преобразования в браузере нет: браузер разбирает HTML и строит DOM, а CSS оформляет уже размеченные элементы. Для автоматической загрузки CSV/JSON понадобился бы JavaScript.
3. Проверка пустых обязательных полей, неверного адреса электронной почты и значения часов вне диапазона 1–40 выполняется нативной валидацией HTML. Форма не выполняет реальную отправку.
4. При росте проекта данные следовало бы загружать программно, компоненты и стили разделить по функциям, добавить автоматизированные проверки, обработку ошибок загрузки и отдельный серверный API.
5. После чистого клонирования достаточно открыть `index.html` согласно этому README: зависимости отсутствуют. Затем вручную пройти по разделам, отправить незаполненную форму, проверить мобильную ширину и клавиатурный Tab.
6. Семантическая разметка сообщает смысл и роль содержимого (например, `nav` — навигация); визуальное оформление задаёт CSS (цвет, размеры, интервалы и расположение). Смысл страницы не должен зависеть только от внешнего вида.
7. В этом проекте браузерный JavaScript не используется. Если он добавлен, он исполняет логику страницы в браузере. Bootstrap JavaScript — код библиотеки Bootstrap для её интерактивных компонентов; Bootstrap в этой работе не подключён.

## Проверка перед отправкой

- Открыть `index.html` и убедиться, что изображения и стили загружаются.
- Проверить меню, переходы к разделам, клавиатурный фокус и поведение при ширине 375–400 px.
- Отправить пустую форму и ввести некорректный email или количество часов за пределами диапазона.
- Инициализировать Git, сделать несколько осмысленных коммитов, отправить проект в свой удалённый репозиторий и передать преподавателю ссылку на корень репозитория.
